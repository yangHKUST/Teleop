# 手持夹爪遥操界面

零基础使用者请先阅读 [项目使用说明](../README.md)。本文件主要说明实现与维护。

独立目录：`/home/taoqiu/UMI_to_OpenArm/teleop_ui`。界面复用原遥操逻辑。准备动作默认到位容差已按需求改为 2°（七个关节最大误差 ≤ 2°，启动及退出返回均适用；可用原 --ready-tol 覆盖）。

## 启动

```bash
bash /home/taoqiu/UMI_to_OpenArm/teleop_ui/run_ui.sh
```

打开界面本身不启动机械臂。选择左臂、右臂或双臂后点击“启动系统”，会运行原有真机启动脚本。
默认双臂、教学输出、VIO 不开窗。模式、输出方案、VIO 开窗选项在运行及退出清理期间锁定。
相机配置沿用原脚本：左 s200085，右 s200086；支持原有 LEFT_VIO_SN/RIGHT_VIO_SN、LEFT_YAML/RIGHT_YAML 环境变量。
状态卡按这些环境变量显示实际选定的序列号。

```bash
# 离线查看界面，不启动相机、ROS 或机械臂
bash /home/taoqiu/UMI_to_OpenArm/teleop_ui/run_ui.sh --demo
```

界面解释器默认 `/home/taoqiu/miniconda3/bin/python`，可用 OPENARM_UI_PYTHON 指定已安装 PySide6 的 Python。
现有启动脚本仍自行激活 ROS 与 piper_pinocchio 环境。

## 操作

点击终端区域获得焦点，仅在原程序等待确认时按 Enter。双臂先统一标定确认，再统一启动确认。
程序输出不可编辑，不提供命令输入；可复制、滚动。向上滚动后取消跟随最新，可勾选恢复。
运行阶段使用底部按钮或终端内 Space/H/S/R/Esc。Ctrl+C 复制文本，退出使用按钮。

- 暂停跟随：原 Space 离合，已有平滑目标仍可能继续收敛。
- 返回准备位姿：原 H 返回末端目标，不保证恢复相同关节构型；原 H 也会解除软件急停。
- 保存新准备姿态：原 S，两侧独立保存新鲜反馈，分别报告结果。
- 恢复默认准备姿态：原 R，更新配置，不直接回位；更新准备参考仍按原 IK 逻辑处理。
- 退出系统：原 SIGINT/清理流程，正常退出尝试返回准备姿态，急停状态保持冻结。
- 软件急停：原 Esc，只在运行循环已启动后可用。

## RViz：完整模型与实时反馈

点击“启动系统”后，同时启动独立的只读显示进程，不依赖 CAN 或控制器就绪。
显示 URDF 位于原项目 `UMI_to_arm/arm/mujoco_sim/urdf/openarm_bimanual.urdf`，包含双臂与夹爪。

- 从未收到有效反馈：完整默认准备姿态，标注“无反馈 · 默认姿态预览”。
- 某侧七个关节均收到新鲜有限反馈：该侧切换为“实时反馈”。
- 反馈中断：保留该侧最后姿态，明确标注“反馈中断 · 保留最后姿态”。
- 单臂模式未启用侧：默认姿态，标注“未启用 · 默认姿态预览”。
- 真机启动失败或正常退出：模型显示保持可用，不随控制脚本退出消失。

显示进程仅订阅 `/joint_states`。预览的 robot_description、TF 和静态 TF 全部发布到随机唯一
`/openarm_ui_view_<uuid>/...` 话题；独立 RViz 也只消费这些显示话题。
不发布 `/joint_states`、`/tf`、`/tf_static`，不写控制器命令，不使用目标角冒充实测角。
不改原启动流程、映射、IK 或机械臂控制逻辑。

UI 在 X11/xcb 下嵌入专用 RViz 主窗口，排除闪屏、验证实际父窗口，并随界面缩放。
原启动脚本附带的 RViz 仅隐藏窗口，继续保留原控制进程。
显示配置使用独立副本，隐藏多余侧栏，以完整模型为主；原配置文件不变。
关闭 UI 时清理自己的显示进程。没有图形会话时不会把未成功显示的模型报告为已嵌入。

## 数据与实现边界

PTY 提供真正的控制终端以兼容现有 `/dev/tty` 和 KeyboardReader；所有操作仍经原启动脚本和控制核心。
完整 JSON 行日志位于 `teleop_ui/logs/<会话>/left.log`、`right.log`，不生成运行 CSV。
界面状态来自日志和原确认提示；提示文字若将来变更，需更新 UI 的确认识别。
开发者完整关节/位姿仍留在日志中，终端每秒显示原摘要。
主题切换不改变控制行为。日志尾读及显示在界面进程中进行。
