# 手持夹爪遥操机械臂：零基础使用说明

本项目让你用手中的夹爪控制 OpenArm 机械臂。你移动、转动手持夹爪，机械臂末端会按照程序的映射跟随；手持夹爪开合连接正常时，机械臂夹爪也会跟随开合。

这份说明面向第一次使用系统的老师和学生，不要求会编程。建议第一次操作由熟悉设备的老师带着完成。

**第一次使用，先阅读“认识界面”和“完整操作步骤”。不要把看到模型当作机械臂已经连接成功。**

> 本文的命令适用于当前交付电脑，项目路径为 `/home/taoqiu/UMI_to_OpenArm`。如果换了一台电脑，需要维护人员先完成软件安装、相机配置和机械臂通信配置，不能只复制本文件中的命令。

## 1. 先认识几样东西

| 名称 | 可以怎样理解 |
|---|---|
| 手持夹爪 | 你拿在手里操作的设备，是机械臂的“遥控器” |
| 机械臂末端夹爪 | 安装在机械臂最前端、实际抓取物体的夹爪 |
| 左臂／右臂 | 软件中分别配置的两条机械臂，第一次使用请由老师指认对应关系 |
| 遥操 | “远程操作”的简称，本项目指用手持夹爪控制机械臂 |
| UI | 操作界面，也就是有按钮和模型的窗口 |
| VIO | 利用相机和惯性传感器估计手持设备的位置与朝向；可以理解为“视觉定位” |
| RViz | 用来显示机械臂三维模型的软件，已经放进界面左侧 |
| 关节反馈 | 真机告诉电脑“我现在各个关节转到了哪里” |
| CAN | 电脑与机械臂通信使用的接口；连接正常才能获得真机反馈并控制运动 |
| 准备姿态 | 开始操作前机械臂要去的姿态，也可以由使用者保存自己的姿态 |
| 方向标定 | 让程序知道手持设备的方向与机械臂方向如何对应 |
| Enter | 键盘上的回车键，常标成 `Enter` 或 `↵` |
| 日志 | 程序自动保存的运行记录，出现问题时供维护人员查看 |

不用记住所有技术名词。实际操作主要是：选择模式、启动、看提示、确认标定、确认开始、操作、退出。

## 2. 使用前需要什么

### 2.1 当前电脑应当已经配置好

这份说明假设交付电脑已经安装并配置好界面、机械臂控制软件、相机定位软件和模型文件。

如果出现“文件不存在”“缺少 Python 模块”或软件根本无法打开，请先找维护人员。普通使用者不需要自行安装 Python、ROS 或修改程序。

### 2.2 实际操作前检查设备

请在点击“启动系统”之前完成这些准备：

1. 机械臂已按设备说明接好电源和通信线。
2. 手持夹爪上的相机已连接到电脑，镜头没有遮挡。
3. 如需开合跟随，手持夹爪的开合通信设备也已连接。
4. 机械臂周围留有运动空间；因为启动和正常退出都可能让机械臂移动。
5. 确认要使用左臂、右臂还是双臂。

机械臂的电源、接线、CAN 接口初始化方式，请按交付设备的操作说明执行。程序启动命令本身不能代替这些连接工作。

**手持夹爪开合设备未连接时，程序会提示并自动跳过开合跟随。相机位姿定位和机械臂连接仍然需要正常，才能进行位置、朝向遥操。**

## 3. 打开界面

### 3.1 普通使用

在当前交付电脑上：

1. 打开 Linux 的“终端”应用。通常可按 `Ctrl + Alt + T` 打开。
2. 复制下面整行命令，粘贴到终端中。Linux 终端通常使用 `Ctrl + Shift + V` 粘贴。
3. 按键盘上的 `Enter`。

```bash
bash /home/taoqiu/UMI_to_OpenArm/teleop_ui/run_ui.sh
```

稍等，操作界面就会打开。

**打开界面不等于启动真机。只有在界面中点击“启动系统”，才会运行机械臂启动流程。**

建议保留启动界面的外部终端，不要随意关闭。后续操作主要在 UI 内完成。

### 3.2 只想先看界面，不操作设备

使用下面的演示命令：

```bash
bash /home/taoqiu/UMI_to_OpenArm/teleop_ui/run_ui.sh --demo
```

这个模式只演示界面和模拟文字：

- 不启动机械臂。
- 不启动相机或实际模型显示进程。
- 显示“已连接（演示）”等文字，不表示真实设备已连接。
- 启动和控制按钮不可用。

体验完后关闭演示窗口。实际使用时重新运行不带 `--demo` 的命令。

## 4. 认识界面

界面主要分成四块。

### 4.1 顶部：选择怎么运行

| 选项 | 说明 | 初次使用建议 |
|---|---|---|
| 控制模式 | 左臂、右臂、双臂 | 按老师安排选择；默认双臂 |
| 输出 | 教学、开发者 | 选择教学 |
| 主题 | 浅色、深色 | 按个人阅读习惯选择 |
| 显示 VIO 窗口 | 是否额外打开视觉定位的点云和图像窗口 | 初次使用可不勾选 |

“教学”用中文解释运行状态；“开发者”显示更多数值，供维护人员排查问题。

点击“启动系统”后，控制模式、输出方案和 VIO 窗口选项会锁定。必须退出当前运行并等清理完成后，才能更改。

“显示 VIO 窗口”和左侧模型不是一回事。不勾选 VIO 窗口，仍然可以看到机械臂模型，也不会关闭视觉定位。

### 4.2 左侧：机械臂三维模型

这里可以看到躯干、左右臂和夹爪。模型显示启动后，通常可以拖动鼠标旋转视角，用滚轮缩放。

**先看模型下方的文字，判断它是预览还是真实反馈：**

| 模型下方的说明 | 意思 |
|---|---|
| 无反馈 · 默认姿态预览 | 没有真机反馈，显示的是预设姿态 |
| 实时反馈 | 该侧模型使用收到的实测关节角 |
| 反馈中断 · 保留最后姿态 | 曾经收到反馈，但现在中断了；画面停留在最后状态 |
| 未启用 · 默认姿态预览 | 当前模式没有启用该侧，显示只是预览 |

左右臂可以处于不同的显示状态，需要分别查看。

**看到完整模型，甚至看到模型摆在准备姿态，都不表示真机已经准备到位。**是否连接、是否到位，要同时查看右侧状态和终端提示。

### 4.3 右侧上方：连接和准备状态

每条臂分别显示：

- **控制连接**：机械臂反馈是否可用。
- **视觉位姿**：相机定位数据是否可用。
- **手持夹爪**：开合跟随是否启用。
- **准备动作**：是否正在回准备姿态、已到位或超时。
- **准备配置**：使用默认姿态还是保存的自定义姿态。

黄色或错误文字出现时，先阅读具体原因。不要只看模型是否存在。

### 4.4 右侧下方：界面里的终端输出

这里显示程序正在做什么，以及接下来需要你做什么。

这块区域可以滚动、选择和复制文字，**不能像电脑终端那样输入命令**。

需要确认时：

1. 用鼠标点击一次终端文字区域。
2. 按一下 `Enter`。
3. 等待新的提示。

只有程序正在等待确认时，回车才会生效。不要连续敲回车，避免没看清下一步提示。

如果向上滚动查看旧消息，新消息可能不再自动滚到眼前。勾选“跟随最新”即可恢复。

## 5. 完整操作步骤：以双臂为例

### 第一步：选择双臂和教学输出

打开普通 UI 后，确认顶部：

- 控制模式：**双臂**。
- 输出：**教学**。
- 是否显示 VIO 窗口：按需要选择。

### 第二步：点击“启动系统”

系统会连接机械臂，并启动左侧模型显示。

即使真机连接失败，也可能看到完整的默认姿态预览。此时仍然不能进行真实遥操，请以连接提示为准。

### 第三步：等待双臂准备动作

当真机连接正常时，左右臂会并行执行各自的准备动作。

默认准备姿态为：

> 大臂竖直向下，小臂和夹爪水平向前。

如果之前保存过自定义准备姿态，该侧启动时会优先使用保存的姿态。

当前到位判断是：该侧七个关节的最大误差不超过 **2°**，并且必须有有效的新鲜反馈。准备超时不能当作已经到位；原程序可能提示后继续后续流程，使用者仍需留意实际位置。

### 第四步：等待两路视觉定位就绪

两侧准备阶段结束后，两路 VIO 会并行启动。

请保持相机视野清晰，按终端提示等待定位数据。定位初始化可能需要一定时间；未就绪时不能完成方向标定。

勾选了 VIO 窗口时，会额外看到点云、双目彩色和跟踪图像等窗口。没有勾选时，定位仍在后台运行。

### 第五步：摆好左右手持夹爪，确认方向标定

看到方向标定提示后：

1. 按终端说明摆好左右手持夹爪，让手指保持水平、指向提示要求的工作区，相机保持正确安装朝向。
2. 保持两个手持夹爪静止。
3. 点击 UI 中的终端输出区域。
4. 按一次 `Enter`。

一次确认会让左右两侧分别计算自己的方向映射。不是把一侧的标定结果直接复制给另一侧。

当前标定采用摆朝向的方法，不需要额外分别沿上下、前后推动来记录起终点。

第一次使用时，请让老师示范夹爪应该朝哪个方向，不要仅凭左右名称猜测。

### 第六步：确认开始遥操

两侧标定成功后，终端会提示再次按回车开始。

1. 看清这个新的开始提示。
2. 保持夹爪稳定。
3. 点击终端输出区域，再按一次 `Enter`。

程序随后检测手持夹爪开合连接；未连接则明确提示并自动跳过，然后进入位姿遥操。

因此双臂通常需要两次不同的确认：**第一次确认方向标定，第二次确认开始遥操。**

### 第七步：开始跟随操作

进入运行状态后，缓慢、小幅移动和转动手持夹爪，观察对应机械臂和模型的反馈。

如果手持夹爪开合已启用，还可以观察机械臂夹爪的开合跟随。

底部按钮会在原程序进入运行阶段后启用。启动过程中按钮暂时不可用，是为了避免向尚未准备好的程序发送运行操作。

### 第八步：结束使用

使用“退出系统”，等待返回／保持动作和程序清理结束。具体说明见[第 10 节](#10-正确结束一次使用)。

## 6. 六个按钮分别做什么

| 按钮 | 用途 | 需要知道的实际行为 |
|---|---|---|
| 暂停跟随／恢复跟随 | 暂停或恢复手持运动跟随 | 暂停停止接收手持运动增量；机械臂仍可能向已有目标继续平滑收敛，不等同于急停 |
| 返回准备位姿 | 将末端目标设回当前准备位姿 | 会产生运动；不保证所有关节恢复为保存时完全相同的构型 |
| 保存新准备姿态 | 把当前实测关节姿态保存为新的准备配置 | 会影响本次返回目标和下次启动使用的姿态 |
| 恢复默认准备姿态 | 清除自定义配置，恢复默认 | 这个按钮本身不直接执行回位；需要回位时再点“返回准备位姿” |
| 退出系统 | 结束当前运行 | 正常运行状态下尝试返回准备姿态；软件急停状态下保持冻结并退出 |
| 软件急停 | 执行原程序的软件急停 | 运行阶段可用，与暂停及正常退出不是同一种操作 |

**注意：当前“返回准备位姿”沿用原来的 `H` 操作，也会解除软件急停并设定返回目标。软件急停后，不要把这个按钮当作一个只查看状态的按钮。**

### 按钮作用于哪条臂？

- 左臂模式：作用于左臂。
- 右臂模式：作用于右臂。
- 双臂模式：向左右两侧发送操作，两侧分别执行。

保存和恢复可能出现一侧成功、一侧失败，需要分别看结果，不能只凭一次点击就认为两侧都成功。

### 可以使用键盘吗？

运行时，先点击终端区域获得焦点，可以使用这些快捷键：

| 键 | 对应操作 |
|---|---|
| `Space`，空格键 | 暂停／恢复跟随 |
| `H` | 返回准备位姿 |
| `S` | 保存新准备姿态 |
| `R` | 恢复默认准备配置 |
| `Esc` | 软件急停 |

初次使用建议点击按钮，更容易看懂动作含义。

UI 里的 `Ctrl + C` 用于复制文字，不是退出快捷键。退出请点击“退出系统”。

## 7. 如何保存和恢复准备姿态

### 7.1 保存自己的准备姿态

例如，你希望下一次启动时使用当前机械臂姿态：

1. 在正常遥操中把机械臂移动到希望使用的姿态。
2. 让姿态稳定下来，确认有正常反馈。
3. 点击“保存新准备姿态”。
4. 查看终端中的成功或失败提示。

保存成功后：

- 配置写入文件，关闭程序后仍然保留。
- 本次点击“返回准备位姿”会使用更新后的准备末端目标。
- 下次启动会优先使用保存的自定义准备关节姿态。

双臂模式会分别保存左右臂当前姿态。某侧反馈缺失或过期时，该侧不会保存，但另一侧仍可能成功。

### 7.2 恢复默认准备配置

1. 点击“恢复默认准备姿态”。
2. 查看每一侧是否恢复成功。
3. 如果希望现在返回，另行点击“返回准备位姿”。

恢复默认配置不会立即让机械臂回位。如果遥操仍在运行，它仍然会按原有跟随和姿态参考逻辑工作；希望暂时停止手持跟随时，应先点击“暂停跟随”。

恢复成功后，下次启动使用默认准备姿态：大臂向下，小臂和夹爪水平向前。

### 7.3 模型预览与准备配置不是一回事

无反馈时左侧显示的是**内置默认姿态预览**。即使右侧显示准备配置为“自定义”，静态模型也不能证明真机正处在该自定义姿态。

只有“实时反馈”模型才代表收到的真实关节位置。

## 8. 如何只控制一条机械臂

1. 如果正在运行，先点击“退出系统”。
2. 等待退出和清理完成，控制模式选项重新变为可选。
3. 选择“左臂”或“右臂”。
4. 点击“启动系统”。
5. 按该侧的终端提示完成准备、方向标定和开始确认。

单臂模式仍可看到完整双臂模型，但未启用侧会标为预览，不代表它也进入了遥操。

不能在运行中直接从左臂改成右臂，或从单臂改成双臂。

## 9. 怎样看懂模型和提示

### “有模型”不等于“已连接”

项目中的模型文件可以让电脑画出完整机械臂。画出模型不需要真机通信正常。

真机的实时姿态则需要关节反馈。因此，机械臂没连接时，模型可以完整显示，但只能叫预览。

### 第一次收到反馈时，模型可能跳一下

当前实现会从默认预览直接切换到实测姿态，没有加入平滑显示过渡。

如果真机姿态与预览不同，画面可能明显变化。这只是显示切换，本身不会向真机发出“跳到这个姿态”的命令。

### 模型不动，不一定是程序卡住

先看下方文字和终端：

- 默认姿态预览：没有实时反馈，本来就不会跟随真机。
- 反馈中断：画面保留最后位置。
- 暂停跟随：手持运动不再被跟随。
- 软件急停：程序处于急停保持状态。

不要通过反复点启动或回位来判断程序是否正常。

### 手持夹爪“已跳过”是什么意思？

表示开合通信没有启用，机械臂夹爪不会跟随手持夹爪开合。它与相机定位是两个不同的连接。

如果相机和机械臂连接正常，位置、朝向遥操可以继续。

## 10. 正确结束一次使用

### 10.1 正常结束

1. 稳定手持设备，停止不必要的输入。
2. 确认机械臂返回准备姿态的路径有空间。
3. 点击“退出系统”。
4. 等待终端报告退出结果和清理完成。
5. 如果不再使用，可以关闭 UI；然后按设备说明关闭硬件电源。

退出期间，选项暂时保持锁定。不要反复点击，不要把等待返回动作当作窗口卡死。

正常退出可能让真机返回准备姿态；如果返回超时，终端会给出结果，不应当认为已成功回位。

### 10.2 已经处于软件急停

此时退出沿用原程序的冻结保持逻辑，不主动执行正常回位。

如果要恢复操作，先由老师或维护人员确认条件，再选择后续动作。“返回准备位姿”会解除软件急停并设定回位目标。

### 10.3 直接关闭 UI 窗口

运行中点击窗口关闭，也会请求原程序正常退出，并等待清理。它不是立即停止动作的操作。

退出真机控制后，完整模型可能仍保留在 UI 中；这不代表控制程序仍在运行。查看右侧“已退出”和终端结果。

## 11. 常见问题

| 现象 | 先做什么 |
|---|---|
| 命令执行后界面没有打开 | 看外部终端报错；如果文件不存在或缺少模块，把报错交给维护人员 |
| 已看到模型，但真机不动 | 检查它是否只是“默认姿态预览”，再看控制连接和终端错误 |
| 提示 `can0`／`can1` 初始化失败 | 检查电源、通信线和适配器；请维护人员检查 CAN 接口配置。不要用模型是否完整来判断通信是否正常 |
| 视觉位姿一直未就绪 | 检查相机连接、镜头遮挡、相机对应关系，并等待定位初始化 |
| 手持夹爪未连接、已跳过 | 当前没有开合跟随；如需要开合，由维护人员检查夹爪通信设备 |
| 按回车没有反应 | 点击 UI 终端文字区，再按一次回车；确认程序确实正在等待确认 |
| 按钮是灰色的 | 可能还在启动、未进入运行阶段或正在退出；按终端提示等待 |
| 准备动作显示超时 | 查看实际位置和反馈，不把超时当作到位；让老师检查后再决定继续或退出 |
| 左右臂保存结果不同 | 两侧独立保存；失败侧保留原配置，按提示检查其反馈 |
| 看不到最新消息 | 勾选“跟随最新” |
| RViz 没进入左侧区域 | 查看终端嵌入错误；当前嵌入依赖 X11/xcb 图形会话，由维护人员检查 |
| VIO 窗口没弹出 | 默认关闭；如需要，退出后勾选“显示 VIO 窗口”，再重新启动 |
| 更改模式的选项不能点击 | 当前会话尚未完全退出，等清理完成后再更改 |

向维护人员反馈时，尽量提供：

1. 使用左臂、右臂还是双臂。
2. 问题发生在启动、标定、运行还是退出阶段。
3. 终端里的具体错误文字或界面截图。
4. 最近一次日志目录。
