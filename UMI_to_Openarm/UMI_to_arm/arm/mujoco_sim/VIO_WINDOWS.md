# VIO 窗口开关

通过 `--vio-cmd` 启动的 Cyperstereo VIO 默认不弹出窗口，视觉追踪和位姿发布继续运行。
在原启动命令末尾（`--vio-cmd` 引号外）追加 `--vio-viewer`，即可显示该相机的点云、双目彩色和跟踪图像窗口。
左臂、右臂和 `run_openarm_dual.sh` 均支持；双臂开启时两侧分别显示窗口。
此参数与 `--output-mode teaching|developer` 独立，可以同时使用。

```bash
# 在原命令后追加：
--vio-viewer --output-mode developer
```

实现通过 VIO 子进程的 `VIO_HEADLESS` 环境变量控制；开启时移除此变量（程序按变量是否存在判断，不能设成 0）。
已经单独启动的 VIO 不受该参数影响，需要通过启动脚本重新启动。
自定义 `--vio-cmd` 应避免自行再次设置 `VIO_HEADLESS`；其他 VIO 程序需要支持该环境变量才会生效。

验证：环境保留、默认关闭、显式开启和真实子进程环境传递测试通过；没有启动相机和真机。

## 双臂并行 VIO 与统一标定

双臂启动流程：控制连接 → 两臂同时准备 → 两路 VIO 并行启动 → 两侧新鲜位姿就绪。
摆好左右手持夹爪并保持静止，按一次 Enter，两侧各自读取本相机的新鲜位姿，独立计算方向映射。
两侧标定均成功后，再按一次 Enter 开启双臂遥操。
统一确认是同时放行两个程序，不是硬件同步采样；保持夹爪静止即可。
若任一侧位姿缺失、过期或标定失败，启动流程不会进入遥操，需要处理提示后重新启动。
`--no-calibrate` 跳过标定确认，但仍等待两路 VIO 就绪，并保留最终开启遥操的确认。
单臂流程保持独立标定确认不变。

两侧控制核心就绪后并行执行各自准备动作；两侧准备阶段均结束后才放行 VIO。此为软件并行启动，不保证硬件时钟级同步，也不要求两臂同时到位。
